# Security policy

## Supported version

Security fixes are applied to the current `main` branch until formal releases
and a longer support policy exist.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open
a public issue for an unpatched vulnerability or include credentials, private
corpus content, or exploit details in public benchmark artifacts.

Include affected revisions, reproduction steps, impact, and any suggested
mitigation. Acknowledgement and disclosure timing will be coordinated through
the private report.
